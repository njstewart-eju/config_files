# config_files

Config files (dotfiles) for various things including:
- vim / neovim (vimscript not lua)
- window managers such as qtile (on X11) and niri (Wayland)
- Matlab startup script
- .bashrc 
- tmux 
- desktop files for random applications

Files labeled \_sharc or similar are made for HPC and are distinct from the *usual* configs
